## 隔离内容

每次仅发送当前用户问题，`messages` 只有一条 user 消息。不发送网站的 `SYSTEM_PROMPT`、课程检索结果、资料、附件或历史回答；不传 `response_format`；不解析或修复模型 JSON，不调用 `normalizeCourseResponse`。回答作为原始文本展示，保留空白、字段顺序和 Markdown 围栏。生成参数仍为 `enable_thinking=false`、`max_tokens=8192`、`stream=false`。这些是运行参数，并非回复格式要求。

页面会显示“微调原始输出”，以及模型编号、耗时、Token 用量（平台返回时）和记录保存状态。模型即使输出 JSON，也直接显示 JSON，不转换为课程卡片。每条问题独立发送，“继续推荐”等依赖上下文的提问在该模式下无法获得之前的推荐内容。资料上传与个人信息也不参与该模式回答。

## 观察记录

实际调用后自动追加至 `finetuning/observations/finetune-only.jsonl`，每行记录当前问题、请求和返回模型编号、原始回答、Token 用量、耗时、结束原因及五项隔离标记。上游失败也尝试记录经过现有错误处理器清理的错误；不保存 API Key 或请求头。该目录被 Git 忽略，准备 PPT 时应自行检查并选择分享内容。记录失败会在页面提示，不会伪称已保存。`length` 结束原因保留原文并提示可能截断。

此改动通过本地模拟接口验证，不主动进行付费推理或完整测评。模拟数据只用于测试且在测试后删除，不写入真实观察目录。后续页面上的真实提问会正常产生百炼推理费用。

## 使用与恢复

重启 `npm run dev` 后刷新网页并开启新对话。其他电脑需同步 `server/finetune-only.mjs`、`server/qwen-advisor.mjs`、`src/main.jsx`、`src/course-guide.css`，并在自己的 `.env.local` 中加入 `QWEN_ADVISOR_MODE=finetune-only`。API Key 继续仅由本机后端读取。

恢复完整网站效果：把 `.env.local` 中该值改为 `integrated`，重启服务并新建对话；原提示词和课程卡片逻辑均保留。

## 解读限制

这是一项同时去除提示词、检索、历史和排版的观察，不是仅改变系统提示词的严格单变量实验。训练数据本来包含系统说明及课程资料，当前输入与训练分布不同，因此不能单凭这一模式判断训练成功或失败。模型权重也不能保证记住完整课程数据库；课程事实正确性与格式学习效果需要分别核对。尚未执行相同问题的基础模型对照或独立语义评估，不能把页面格式、训练指标或模拟测试当作模型准确率。

# 课程顾问与微调数据详细审计

日期：2026-11-03。范围：当前项目的课程检索、回复整理、课程卡片显示、开发 API、训练数据生成／审核／导出／上传检查及离线评测。

结论：确认并修复了会导致错误推荐、信息被遮住、异常数据崩溃和旧训练包误用的问题。当前是可以继续验收的本地候选版本，仍不能保证微调效果或官方选课资格。没有启动训练，也没有产生真实模型准确率对比。

## 已确认并修复的问题

严重程度是对本项目的影响排序：P1 表示会阻断流程、误导关键决定或误用数据；P2 表示影响推荐正确性、展示或稳健性。

## 数据审计结果

来源为本地课程快照 2,659 条；本轮纳入 COMP／DSAI／AMA 中信息满足生成条件的 354 门。生成方法仍是确定性模板、课程库摘录及少量 AI 辅助改写，不能当作人工标准答案。

| 分区 | 草稿 | 通过自动规则的候选 | 隔离 |
| --- | ---: | ---: | ---: |
| 训练 | 1,199 | 1,151 | 48 |
| 验证 | 163 | 160 | 3 |
| 独立测试 | 188 | 175 | 13 |
| 合计 | 1,550 | 1,486 | 64 |

隔离原因包括机械化片段、学习目标过少／过长、主题碎片及来源中的 XR 译法歧义。同一样本可能触发多条规则，问题类型计数不能直接相加当作隔离总数。通过规则的样本也可能有规则未发现的错误。

人工语义审核通过数：**0**。训练／验证候选位于 `finetuning/v8/reviewed-release/`，独立测试候选由原 test 集结合 review.json 选择，没有导出到上传包。

每个课程条目的最后一个字段为 preparation；简介、学习目标和总述不放先修条件。prep 的来源原文、编号及分组与本地课程库核对。假评分没有进入训练目标。当前 prompt 与来源哈希一起保存，上传检查已通过本地 dry-run。

使用已缓存的公开 Qwen3 tokenizer 做本地长度估计：训练候选约 2,722,119 tokens，最长 5,646，P95 为 3,049；验证约 365,499，最长 4,274。此估算说明当前候选在拟议的 8,192 长度内，没有证明平台实际计费或训练模板完全一致。预算授权依然为 false。

## 仍然存在的问题与建议顺序

1. **微调效果仍未实测。** 当前页面效果同时依赖基础模型、提示词、检索和服务端整理。服务端把格式修正正确，不代表模型学会。需在同一 Qwen 基础模型和相同输入／参数下，对比微调前后原始输出，再人工标注事实、通俗程度、相关性及遗漏。现在无法承诺训练后达到当前效果。
2. **数据覆盖偏斜。** unknown_semester 草稿有 348 条，而 unknown_eligibility 仅 6 条；很多课程共享问法和句式。需要补真实提问、多轮澄清、课程更换、已修／未修／正在修、代词指代及边界样本，并避免仅增加重复句式。共享任务模板的分区不能检验全新的问法泛化；近似文本分组也不能排除所有语义重复。
3. **尚无官方资格判定器。** Level 分类是展示分组，不能表达所有 AND/OR、互斥、同修及专业限制。页面按用户要求使用建议先修，但不能据此把课程库必要条件变成可选；原文只保留在响应校验字段，分组页面没有展示完整逻辑。当前只明确提示尚未核验，不能证明能否正式选课。
4. **文件解析有限。** TXT／CSV 等文本会读取，PDF／DOCX／XLSX 仍只传文件名和大小。已增加模型不得声称读过二进制内容的指令，但指令不能代替解析功能。因此仍不能声称已经理解成绩单或毕业要求；实现解析后还需做来源页码与证据核对。
5. **检索与多轮理解有限。** 当前主要依赖关键词和扩展词，没有完整语义检索；新增同义词不能覆盖所有方向。“这门课”在前文有多门课程时仍可能指错，复杂否定和跨消息已修信息不保证全部识别。相关性与这些多轮情景需要实际评测和澄清设计。
6. **模型内容仍可能编造。** 当前校验能约束课程编号、元数据、先修和结构，但不会逐句证明简介／学习目标的事实。提示词增加了资料内指令隔离，也不能证明抵御所有提示注入。需要来源标注、语义验收和真实对抗评测。
7. **安全范围限于本地开发。** 已增加 Host／Origin／大小／时限边界，但没有公网多用户认证、配额、限流与完整审计机制；本轮没有检查真实 Supabase RLS 或生产部署权限。直接公网开放仍不在已验证范围内。
8. **示例评分不是学生口碑。** 仍明确标记“示例”；进程内保持稳定，重启可改变。只能用于 UI 演示，不能用于证明真实课程评价或模型推荐质量。

建议下一步先抽查并改写有代表性的候选样本、补齐上述真实场景，再验收数据和确认训练预算。获得授权后才进行付费基线评测与小规模训练。本轮未上传 v8、未创建训练任务、未修改预算许可；历史 v5 远端文件保留且作废，v6／v7 本地包已标记作废。
